Backup dos relatórios

Exporta todos os relatórios (de todos os tipos de processo, com fotos e histórico), as configurações e o arquivo de mapa para um único arquivo. Use para guardar uma cópia ou levar os dados para outro aparelho. Ao importar, nada é apagado: relatórios novos são adicionados e os já existentes só são trocados se o arquivo tiver uma versão mais recente.

Google Drive

Entre com sua conta Google para enviar relatórios e fotos a uma pasta do seu Drive. O app só acessa os arquivos que ele mesmo criar.

Ordem de prioridade das vistorias

Um loteamento por linha, do primeiro ao último. A rota segue essa ordem; dentro de cada loteamento, os processos ficam do mais próximo ao mais próximo. Loteamentos que não estão na lista vão depois.

Aplicativo de mapa

Mapa (arquivo GeoJSON)

Carregue um GeoJSON com os pontos e escolha o atributo que contém a inscrição imobiliária. Cada processo com a mesma inscrição ganha um link para abrir o local no mapa escolhido acima (Google Maps ou OpenStreetMap). O arquivo é lido no próprio aparelho.
